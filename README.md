# GIGA-CLASH（ギガ・クラッシュ）

**街で守れ。そして、乗り込め。**
ヒーロー4人 vs 怪人4人。前半は街で市民と拠点を奪い合い、後半は4人で1体の巨大ロボ／大怪獣に乗り込んで戦う、特撮パーティーアクションです。

▶ **遊ぶ：https://kt2reft.github.io/giga-clash/**

- ブラウザだけで遊べます（PC・スマホ。スマホは横向きがおすすめ）
- コントローラー対応（つなぐだけで使えます）
- 同じ画面で最大4人（コントローラーの台数分）
- オンライン対戦：最大8人。足りない席はBotが入ります
- はじめての人には「ナビ」が次にやることを案内（ロビーでOFFにできます）
- 上級者向け：コンボ、ジャストガード、動力炉の最適出力、難易度「げきむず」、自己ベストスコア
- 巨大戦はジャンプで相手を飛び越えて左右を入れ替えられる（ジャンプキック・対空・脚部が壊れると跳べない）
- ヒーロー4人・怪人4人それぞれに固有スキル（ロビーの「キャラ」で選ぶ）

## オンライン対戦のやり方

1. タイトルで「オンライン」→「部屋を作る」
2. ロビーの「招待リンクをコピー」を押して、友だちに送る（または5文字の部屋コードを伝える）
3. 友だちがリンクを開くと、自動で同じ部屋に入る
4. 全員そろったら、部屋を作った人（ホスト）が「スタート！」

通信はブラウザ同士の直接接続（WebRTC）です。相手を見つけるときだけ PeerJS の公開サーバーを使います。
会社や学校のネットワークなど、一部の環境ではつながらないことがあります。

## 操作

| | キーボード | コントローラー |
|---|---|---|
| 移動 | WASD | 左スティック / 十字キー |
| つかむ・入れる・作業（長押し） | Space | Ⓐ |
| パンチ・弱攻撃（連打でコンボ） | J | Ⓧ |
| 投げる・強攻撃 | K | Ⓑ |
| ガード（当たる直前でジャストガード） | L（長押し） | RB / RT |
| 飛び道具 | U | LB / LT |
| ジャンプ（操縦中） | W / Space | ↑ / Ⓐ |
| スキル（前半戦・裏方）／必殺技（操縦中） | I | Ⓨ |
| 緊急脱出（操縦席から） | X | Back |
| 一時停止 | Esc | Start |

## キャラと固有スキル

| チーム | キャラ | 前半戦のスキル | 裏方のスキル | いつも効く特徴 |
|---|---|---|---|---|
| ヒーロー | 司令塔 | 号令：近くの仲間が速くなる | 号令：裏方全員がパワーアップ | 拠点の確保が速い／操縦で疲れにくい |
| ヒーロー | 突撃隊長 | タックル | 消火ブラスト | 重い市民も速く運ぶ／パンチが強い |
| ヒーロー | メカニック | バリア | クイック修理 | 修理・消火が速い |
| ヒーロー | スピードスター | ソニックブースト | ジェットダッシュ | いつも少し速い |
| 怪人 | 大幹部 | 咆哮：近くのヒーローを止める | 咆哮：裏方全員がパワーアップ | 拠点の確保が速い／支配で疲れにくい |
| 怪人 | 暴れ角 | ヘッドバット | 活性ブラスト | 重い市民も速く運ぶ／パンチが強い |
| 怪人 | 毒使い | 粘着トラップ | 神経リンク | 修理・活性化が速い |
| 怪人 | 触手使い | 触手キャッチ | 触手ダッシュ | いつも少し速い |

## フォルダ構成

```
src/          ゲームのソース（ここを編集する）
  sim.js        ルール・Bot・バランス（数値は先頭の BAL にまとまっています）
  render3d.js   3D描画（Three.js）
  hud.js        画面の文字・メニュー
  audio.js      効果音・BGM（すべてブラウザ内で合成）
  main.js       入力・画面の流れ・オンライン同期
  net-peer.js   claude.ai の外でのオンライン通信
  index.html    HTMLのひな形
tools/        ビルド・確認用スクリプト
docs/         公開されるファイル（ビルドで自動生成。直接編集しない）
```
