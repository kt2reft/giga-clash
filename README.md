# GIGA-CLASH（ギガ・クラッシュ）

**街で守れ。そして、乗り込め。**
ヒーロー5人 vs 怪人5人。前半は街で市民と拠点を奪い合い、後半は5人で1体の巨大ロボ／大怪獣に乗り込んで戦う、特撮パーティーアクションです。

▶ **遊ぶ：https://kt2reft.github.io/giga-clash/**

- ブラウザだけで遊べます（PC・スマホ。スマホは横向きがおすすめ）
- コントローラー対応（つなぐだけで使えます）
- 同じ画面で最大4人（コントローラーの台数分）
- オンライン対戦：最大10人。足りない席はBotが入ります
- はじめての人には「ナビ」が次にやることを案内（ロビーでOFFにできます）
- 上級者向け：コンボ、ジャストガード、動力炉の最適出力、難易度「げきむず」、自己ベストスコア
- 巨大戦はジャンプで相手を飛び越えて左右を入れ替えられる（ジャンプキック・対空・脚部が壊れると跳べない）
- ヒーロー5人・怪人5人それぞれに固有スキル（ロビーの「キャラ」で選ぶ）
- ヒーローは戦隊風のスーツ、怪人は角とトゲの前かがみ。足元の輪の色でも見分けられる（ヒーロー：水色、怪人：赤紫）

## オンライン対戦のやり方

1. タイトルで「オンライン」→「部屋を作る」
2. ロビーの「招待リンクをコピー」を押して、友だちに送る（または5文字の部屋コードを伝える）
3. 友だちがリンクを開くと、自動で同じ部屋に入る
4. 全員そろったら、部屋を作った人（ホスト）が「スタート！」

通信はブラウザ同士の直接接続（WebRTC）です。相手を見つけるときだけ PeerJS の公開サーバーを使います。
会社や学校のネットワークなど、一部の環境ではつながらないことがあります。

## 操作

ゲーム内の「遊び方」に、キーボード・コントローラー（Xbox／PlayStation／Switch の表記を切り替え可能）・スマホそれぞれの図入りの説明があります。
コントローラーをつなぐと種類を自動で判別し、画面に出るボタン表記もそのコントローラーに合わせて変わります。

### キーボード

| | 前半戦・裏方 | 操縦中（後半戦） |
|---|---|---|
| 移動 | WASD / 矢印キー | A・D |
| かつぐ・拾う・入れる・作業（長押し）・連打 | Space | — |
| ジャンプ | — | W / Space |
| パンチ／弱攻撃（連打でコンボ） | J | J |
| 投げる／強攻撃 | K | K |
| ガード（当たる直前でジャストガード） | — | L / Shift |
| 飛び道具 | — | U |
| キャラ固有スキル／必殺技 | I | I |
| 緊急脱出（操縦を交代） | — | X |
| 逆境カードを選ぶ | 1・2・3 | |
| 一時停止 | Esc | Esc |

### コントローラー

ボタンは位置で決まっています（下・右・左・上）。

| | Xbox | PlayStation | Switch |
|---|---|---|---|
| 移動 | 左スティック / 十字キー | 左スティック / 十字キー | 左スティック / 十字キー |
| かつぐ・作業（長押し）・連打／操縦中はジャンプ（十字↑も可） | Ⓐ | ✕ | Ⓑ |
| パンチ／弱攻撃 | Ⓧ | □ | Ⓨ |
| 投げる／強攻撃 | Ⓑ | ○ | Ⓐ |
| キャラ固有スキル／必殺技 | Ⓨ | △ | Ⓧ |
| ガード | RB / RT | R1 / R2 | R / ZR |
| 飛び道具 | LB / LT | L1 / L2 | L / ZL |
| 緊急脱出 | View | Create | − |
| 一時停止 | Menu | Options | ＋ |
| メニューの決定／もどる | Ⓐ／Ⓑ | ✕／○ | Ⓐ／Ⓑ |

### スマホ・タブレット（横向き）

- 画面の左半分をなぞって移動（指を置いた所がスティックの中心）
- 右下のボタンで操作。前半戦は「かつぐ・パンチ・投げる・スキル」、裏方は「アクション・投げる・スキル」
- 操縦中は「ジャンプ・弱・強・ガード・飛び道具・必殺・脱出」に変わる

## フォルダ構成

```
src/          ゲームのソース（ここを編集する）
  sim.js        ルール・Bot・バランス（数値は先頭の BAL にまとまっています）
  render3d.js   3D描画（Three.js）
  hud.js        画面の文字・メニュー
  audio.js      効果音・BGM（すべてブラウザ内で合成）
  main.js       入力・画面の流れ・オンライン同期
  net-peer.js   claude.ai の外でのオンライン通信
  index.html    HTMLのひな形
tools/        ビルド・確認用スクリプト
docs/         公開されるファイル（ビルドで自動生成。直接編集しない）
```
